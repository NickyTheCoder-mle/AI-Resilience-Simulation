## 📊 Overview
This repository contains the mathematical simulation verifying the performance of the AI-Resilience platform. Due to the sensitive nature of real-time disaster SOS datasets, we developed a **Monte Carlo Simulation** to load-test our architecture against a historical disaster peak-hour scenario (3,000 concurrent signals).

## 🧠 Core Algorithms
Our system is built on 4 foundational pillars:
1. **Queueing Theory:** Cloud-concurrency handling to reduce SOS drop rates from 68% to <1%.
2. **DBSCAN Clustering:** Density-based spatial noise reduction using Haversine distance.
3. **Dynamic Programming:** Graph theory implementation for dynamic obstacle avoidance.
4. **Linear Algebra:** Matrix transformation for proactive flood propagation prediction.
